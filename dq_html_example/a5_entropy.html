Энтропия Шеннона отвечает на вопрос «сколько информации в одном значении этого поля». Поле с равномерным распределением — высокая энтропия (много вариативности). Поле, где 99% это одно значение — низкая (предсказуемо, малоинформативно).

Формула

H(X) = − Σ p(xᵢ) · log₂(p(xᵢ))

где p(xᵢ) = доля значения xᵢ в столбце. Максимальная энтропия для k уникальных значений = log₂(k) — достигается при равномерном распределении.

Нормализованная энтропия = H(X) / log₂(k) × 100% — позволяет сравнивать поля с разной кардинальностью.

SQL

WITH counts AS (
  SELECT 'status' AS field, status::text AS val, COUNT(*) AS cnt
  FROM mos.address_reestr WHERE status IS NOT NULL AND status <> ''
  GROUP BY status
), totals AS (
  SELECT field, COUNT(*) AS k, SUM(cnt) AS n FROM counts GROUP BY field
)
SELECT field, n AS rows, k AS distinct_v,
  ROUND(SUM(- (cnt::numeric/n) * (LN(cnt::numeric/n) / LN(2)))::numeric, 3) AS entropy_bits,
  ROUND((LN(k)/LN(2))::numeric, 3) AS max_entropy,
  ROUND(SUM(- (cnt::numeric/n) * (LN(cnt::numeric/n) / LN(2)))::numeric / (LN(k)/LN(2))::numeric * 100, 1) AS norm_pct
FROM counts JOIN totals USING(field)
GROUP BY field, n, k;

Что говорит энтропия о DQ

1. l1_value: 21 106 уникальных значений типа здания — это flag. Тип здания (жилое / нежилое / гараж / ...) должен иметь ~10–30 категорий. 21 тысяча — это значит, что в поле попадают free-text описания, а не категориальное значение. Высокая кардинальность при сравнительно низкой нормализованной энтропии (64%) = «длинный хвост» из тысяч разовых значений. Это прямой кандидат на golden records / справочник в C-этапе.
2. status: норм. энтропия 17.5% — это «бутылочное горлышко». 91% всех записей имеют статус «Внесён в ГКН». Поле есть в схеме, но как DQ-индикатор оно почти не работает: дашборд по статусу будет одним столбиком на 91%. Полезнее — отрицание: «сколько записей НЕ имеют canonical status».
3. p7 (88.2%) и adm_area (78.5%) — здоровые поля для измерения географического разнообразия. На них хорошо строится Top-N violations dashboard.

Дополнительная метрика: Gini (анти-разнообразие)

Если хочется одной цифрой показать «концентрацию», можно использовать Gini-impurity = 1 − Σpᵢ². Для status она ≈ 0.16 (низкое разнообразие). Энтропия и Gini обычно коррелируют, но энтропия более чувствительна к «длинному хвосту».

SQL: один сложный запрос с UNION + GROUP BY + LN(2)-нормализацией, ~3 сек
