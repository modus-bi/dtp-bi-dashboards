# AI Skills для BI аналитики

> Пользовательские команды для работы с данными и дашбордами (формат Agent Skills)

## 📚 Доступные Skills

### `/analyze-data` — анализ данных с выводами
**Что делает:**
- Исследует данные через postgres-mcp
- Проверяет гипотезы
- Находит корреляции и аномалии
- Создаёт визуализацию
- Генерирует **Level 4 выводы** (prescriptive analytics)

**Примеры:**
```bash
/analyze-data sales_2024 "почему упали продажи в Q3"
/analyze-data dtp.accidents "снегопад влияет на тяжесть ДТП?"
/analyze-data "корреляция доставки и NPS"
```

**Результат:** Дашборд с графиком + текстовый блок с:
- Драйверы роста
- Зоны риска
- Приоритетные действия (с дедлайнами и impact!)
- Прогноз

---

### `/create-dashboard` — создание полного дашборда
**Что делает:**
- Исследует источник данных (если нужно)
- Создаёт датасеты с правильным SQL
- Добавляет компоненты (KPI, графики, таблицы)
- Генерирует выводы для графиков
- Автоматический layout

**Примеры:**
```bash
/create-dashboard "продажи за Q4"
/create-dashboard "операционный дашборд: KPI, тренд, топ-10"
/create-dashboard "почему упали продажи в Сибири"
```

**Результат:** Готовый дашборд со всеми компонентами

---

### `/generate-sql` — генерация SQL запроса
**Что делает:**
- Генерирует правильный SQL для BI
- Учитывает ORDER BY, типы, округление
- Добавляет русские названия (AS)
- Валидирует перед выполнением

**Примеры:**
```bash
/generate-sql "топ-10 регионов по продажам"
/generate-sql "динамика выручки по месяцам за 2024"
/generate-sql "корреляция цены и конверсии"
```

**Результат:** SQL готовый для dataset_create_from_sql()

---

### `/explain-chart` — объяснение графика
**Что делает:**
- Получает данные из компонента дашборда
- Анализирует паттерны
- Формулирует Level 4 вывод
- Добавляет текстовый блок к дашборду

**Примеры:**
```bash
/explain-chart 598 0  # Отчёт 598, компонент 0
/explain-chart  # Спросит какой график объяснить
```

**Результат:** Текстовый блок с бизнес-выводом рядом с графиком

## 🎯 Связь между Skills

Skills используют детальные методологии из связанных skills:

| Skill | Использует Skills |
|-------|-----------------|
| `/analyze-data` | `/data-analyst-expert`<br/>`/statistical-analysis` |
| `/create-dashboard` | `/bi-visualization-expert`<br/>`/sql-bi-expert`<br/>`/data-analyst-expert` |
| `/generate-sql` | `/sql-bi-expert` |
| `/explain-chart` | `/data-analyst-expert`<br/>`/statistical-analysis` |

**Reference skills** содержат детальные best practices и справочную информацию.
**Action skills** — это actionable команды которые применяют эти правила.

## 🚀 Как использовать

### Автоматический вызов

AI-агент автоматически вызовет skill если задача подходит:

```
User: "Проанализируй почему упали продажи в Q3"
      ↓
Agent: Вызывает /analyze-data автоматически
```

### Ручной вызов

Используй `/` для вызова команды напрямую:

```
/analyze-data sales_2024 "падение в Q3"
/create-dashboard "продажи Q4"
/generate-sql "топ-10 клиентов"
/explain-chart 598 0
```

### В диалоге

```
User: "Создай дашборд продаж"
Agent: [Создаёт дашборд]

User: "/explain-chart"
Agent: [Объясняет последний график]
```

## 🎯 Workflow: Типовая сессия

```
1. Исследование:
   "Какие данные есть про продажи?"
   → Agent использует postgres-mcp

2. Анализ:
   /analyze-data sales "падение в Q3"
   → Проверка гипотез, находит причину

3. Дашборд:
   /create-dashboard "продажи Q3-Q4 сравнение"
   → Полный дашборд с компонентами

4. Выводы:
   /explain-chart 598 0
   → Добавляет Level 4 вывод к графику

5. Финализация:
   "Примени синюю тему и экспортируй в PDF"
   → Стилизация и экспорт
```

## 🔧 Добавление своих skills

### 1. Создай директорию
```bash
mkdir -p skills/my-skill
```

### 2. Создай SKILL.md
```yaml
---
name: my-skill
description: Что делает и когда использовать
---

# My Skill

Инструкции для AI-агента...
```

### 3. Тестируй
```
/my-skill аргументы
```
