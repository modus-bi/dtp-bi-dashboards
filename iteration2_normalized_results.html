2. Альтернативные метрики для специфичных случаев

Deaths per день/час (H1, H4):
• Учитывает объём трафика (меньше ДТП в дождь/ночью)
• НО смешивает exposure (частота) с risk (тяжесть)
• Не рекомендуется для оценки УСЛОВИЙ риска
• Может использоваться для планирования ресурсов (когда больше абсолютных смертей)

Deaths per capita (H13):
• Нужна для "где опаснее ЖИТЬ"
• Дополняет deaths/1000 ДТП (где опаснее ЕХАТЬ)
• Рекомендуется добавить для полной картины по районам

Летняя метрика (H11):
• Корректирует сезонность
• Рекомендуется использовать вместо годовой (методологически правильнее)

3. Критичные confounding (требуют доп. анализа)

H10 (Возраст ТС ⟷ Возраст водителя):
• Риск ложной корреляции: ВЫСОКИЙ
• Старые люди → старые авто (экономия, привычка)
• Старые люди → медленная реакция → смертность
• Линейная корреляция (r~0.95) слишком идеальная → подозрительно
• Нужна ОБЯЗАТЕЛЬНАЯ проверка!

Методы проверки:
1. Multiple regression: deaths ~ age_vehicle + age_driver (если добавить age_driver в БД)
